# 🐧 Linux Introduction

## 📖 What is Linux?

Linux is a free and open-source operating system kernel created by Linus Torvalds in 1991. It is used in servers, cloud computing, embedded systems, smartphones (Android), supercomputers, and personal computers.

Today, Linux powers most of the internet and is the preferred operating system for Cloud, DevOps, Cybersecurity, and Backend Engineering.

---

# 🖥️ What is an Operating System?

An Operating System (OS) is system software that acts as a bridge between the user and the computer hardware.

Without an operating system, a computer cannot run applications or manage hardware resources.

### Main Functions of an Operating System

- Process Management
- Memory Management
- File System Management
- Device Management
- Security and User Management
- Networking
- Resource Allocation
