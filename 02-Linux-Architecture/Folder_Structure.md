# Understanding the Linux File System

Linux organizes everything in a hierarchical directory structure. Unlike Windows, Linux starts from a single root directory (`/`), and every file or directory exists under it.

```
                    /
          (Root Directory)
                 |
---------------------------------------------------------
|   |    |    |    |    |    |    |    |    |    |     |
bin etc home usr var tmp opt dev proc sys boot root mnt media
```

> **Everything in Linux starts from the Root (`/`) directory.**

---

# Linux Directory Categories

## 1. Symbolic Links

Modern Linux distributions use symbolic links to simplify the filesystem.

| Directory | Points To | Description |
|-----------|-----------|-------------|
| `/bin` | `/usr/bin` | Essential user commands |
| `/sbin` | `/usr/sbin` | System administration commands |
| `/lib` | `/usr/lib` | Shared libraries |

> These directories are symbolic links in Ubuntu 24.04 and newer versions.

---

# 2. Important System Directories

## `/boot`

Contains files required to boot the operating system.

Examples:

- Linux Kernel
- Bootloader files (GRUB)
- Initial RAM filesystem (initramfs)

> In Docker containers, this directory is usually empty or not used.

---

## `/usr`

Contains most applications, libraries, documentation, and utilities installed on the system.

Examples:

- `/usr/bin`
- `/usr/lib`
- `/usr/share`

Think of `/usr` as the **main software installation directory**.

---

## `/etc`

Stores all system configuration files.

Examples:

- User configuration
- Network configuration
- SSH configuration
- DNS configuration

Some common files:

```
/etc/passwd
/etc/hosts
/etc/hostname
/etc/ssh/
```

---

## `/var`

Stores data that changes frequently.

Examples:

- Logs
- Cache
- Databases
- Mail
- Web server data

Common directories:

```
/var/log
/var/cache
/var/lib
```

---

# 3. User & Application Directories

## `/home`

Contains home directories for normal users.

Example:

```
/home/haseeb
/home/alice
/home/john
```

Each user stores personal files here.

---

## `/root`

Home directory of the **root user**.

```
/root
```

Do not confuse this with the root directory (`/`).

---

## `/opt`

Used to install optional or third-party software.

Examples:

- Google Chrome
- IntelliJ IDEA
- Custom applications

---

## `/srv`

Stores data used by services.

Examples:

- Web server files
- FTP server data
- Application data

Not commonly used inside Docker containers.

---

# 4. Temporary & Virtual Directories

## `/tmp`

Stores temporary files.

Files here may be deleted automatically after reboot.

---

## `/run`

Stores runtime information.

Examples:

- Process IDs (PID files)
- Lock files
- Runtime sockets

Contents are cleared after every reboot.

---

## `/proc`

A virtual filesystem containing information about running processes and the Linux kernel.

Examples:

```
/proc/cpuinfo
/proc/meminfo
/proc/version
```

These files are generated by the kernel.

---

## `/sys`

Another virtual filesystem.

Provides information about:

- Hardware
- Devices
- Kernel settings

Useful for system administration and troubleshooting.

---

## `/dev`

Contains device files.

In Linux, devices are treated as files.

Examples:

```
/dev/null
/dev/sda
/dev/random
/dev/tty
```

---

# 5. Mount Points

## `/mnt`

Used as a temporary mount point.

Example:

```
sudo mount /dev/sdb1 /mnt
```

---

## `/media`

Automatically used when removable devices are connected.

Examples:

- USB Drives
- CDs/DVDs
- External Hard Drives

---

## `/data`

Not a standard Linux directory.

In our Docker container, `/data` is a **bind mount** from the host machine.

Example:

```
Mac:
/tmp/ubuntu-data

↓

Docker Container:
/data
```

Any files created inside `/data` remain available even if the container is stopped or restarted.

# Interview Questions

### Q1. What is the root directory in Linux?

**Answer:**  
The root directory (`/`) is the top-level directory of the Linux filesystem. Every file and directory starts from it.

---

### Q2. Where are configuration files stored?

**Answer:**  
Configuration files are stored in the `/etc` directory.

---

### Q3. Where are log files stored?

**Answer:**  
Most system and application logs are stored in `/var/log`.

---

### Q4. What is the difference between `/` and `/root`?

- `/` is the root of the entire filesystem.
- `/root` is the home directory of the root user.

---

### Q5. Why is `/proc` called a virtual filesystem?

Because its files are generated dynamically by the Linux kernel and do not exist physically on disk.

---

## 💡 Remember This

A simple way to memorize the important directories:

- **`/`** → Everything starts here.
- **`/bin`** → Basic commands.
- **`/etc`** → Configuration files.
- **`/usr`** → Installed software.
- **`/var`** → Logs and changing data.
- **`/home`** → User files.
- **`/root`** → Root user's home.
- **`/tmp`** → Temporary files.
- **`/proc`** → Process information.
- **`/dev`** → Device files.
